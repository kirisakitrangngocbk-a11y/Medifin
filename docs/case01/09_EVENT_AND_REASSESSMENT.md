# Events and reassessment

M10 emits seven sequential factual updates: Sales, Vendor, Liquidity, Store, Digital, Debt and Family/Board. Each update is derived from the implemented Period 1 treatment, timing, priorities and current state. It is recorded once with an event ID and also creates citable event evidence with provenance `Màn 10`.

M11 confirms one of KEEP, CHANGE DIAGNOSIS, CHANGE TREATMENT or CHANGE BOTH. Timing and priorities are immutable there. New evidence waives the change cost only when it directly contradicts the old diagnosis or demonstrates a material invalidated treatment assumption; irrelevant updates do not. Period 1 events remain historical, while any changed treatment is applied once to a separate Period 2 state and approval snapshot.
